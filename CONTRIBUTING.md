# Contributing

This repository publishes public benchmark-facing material only.

## Valid contribution categories

- benchmark packaging improvements
- metadata and schema improvements
- documentation clarifications
- release validation improvements

## Before opening a pull request

- keep sample identifiers stable
- update release notes for public-facing changes
- re-run `python scripts/validate_release.py`
- update checksums when packaged artifacts change

## Out of scope

Do not add private corpus material, internal pipeline code, or private evaluation infrastructure.
