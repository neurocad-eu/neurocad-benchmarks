# Limitations

## What this repository is not

This repository is not a mirror of the internal NeuroCAD corpus.

It does not publish:

- full internal datasets
- private generation logic
- internal model evaluation infrastructure
- production-only scoring pipelines

## Interpretation guidance

Public artifacts here should be read as:

- packaging examples
- release discipline artifacts
- benchmark surface documentation

They should not be interpreted as the full internal training or evaluation stack.
