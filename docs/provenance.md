# Provenance Notes

## What is tracked publicly

The public sample set tracks:

- release identifier
- packaging date
- schema version
- stable case identifiers
- case family and task metadata
- release checksum

## What is intentionally excluded

The public sample set does not disclose:

- internal generation parameters
- private simulation pipelines
- internal scoring infrastructure
- private dataset lineage beyond the public release boundary

## Why this matters

For public diligence, provenance should prove that:

- the package boundary is explicit
- the release can be validated by third parties
- identifiers and metadata are stable within the published release
